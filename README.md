# evgate 
把一台手机，变成整个局域网的上网出口
手机当网关。电脑、平板、电视、游戏机——只要填一个地址，就能用你手机的网。
支持 HTTP / HTTPS / SOCKS4 / SOCKS5 与 PAC 自动配置。不需要 root，不改系统设置，不拆开加密流量。
能共享给哪些设备 设备	填在哪:
Windows / Mac 电脑	系统设置 → 网络 → 代理 → HTTP 代理
平板 / 另一台手机	WiFi 详情 → 代理 → 手动
智能电视 / 机顶盒	网络设置 → 代理服务器
游戏机（PS / Switch）	网络设置 → 代理服务器 → 手动
车机 / 老设备	只要能填 HTTP 代理，就能连
所有这些设备都不需要安装任何软件。填一个地址，就结束了。
