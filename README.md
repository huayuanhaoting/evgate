# evgate  #局域网桥
把一台手机，变成整个局域网的上网出口 
手机当网关。电脑、平板、电视、游戏机——只要填一个地址，就能用你手机的网。 
支持 HTTP / HTTPS / SOCKS4 / SOCKS5 与 PAC 自动配置。不需要 root.
